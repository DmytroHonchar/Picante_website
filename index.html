Welcome in

A polished neighbourhood bistro for unhurried meals

Juniper Table is a fictional restaurant brand created for a production-ready portfolio demo. The concept pairs seasonal produce, confident bistro cooking, low-intervention wines, and a cocktail list built for long dinners and spontaneous walk-ins. Set on a quiet Shoreditch corner, it feels warm, modern, and deliberately easy to enjoy.
